# osu-skills — график навыков текущей карты osu!

Автономный (standalone) wasm-плагин для Overlay Composer. Виджет рисует, как по ходу карты меняется сложность каждого навыка
(stamina, tenacity, agility, precision, reading, memory, accuracy, reaction), и отмечает текущий момент. Это [osuskillsgraph](https://github.com/compico/osuskillsgraph)
и расчёт [go-osu](https://github.com/compico/go-osu) в одном виджете: поднимать go-osu больше не нужно.

## Как работает

1. Виджет подключается к tosu (`ws://127.0.0.1:24050/websocket/v2`) и узнаёт ID сложности, моды (HD, DT, HR, FL…) и время в карте.
2. Он просит у плагина кривые (`POST /plugins/osu-skills/api/curves`). Плагин скачивает файл `.osu` по ID сложности (разрешение `net.http`),
   считает кривые библиотекой [`github.com/compico/go-osu/pkg`](https://github.com/compico/go-osu/tree/master/pkg) и отдаёт их в формате ручки go-osu `/strains`.
3. Виджет рисует график. Пока карта скачивается, плагин отвечает 202, и виджет повторяет запрос; готовые карты и результаты кэшируются в памяти плагина.

Разрешения: `net.http` (только чтобы скачать файл карты).

## Установка

1. Скачайте `osu-skills.wasm` из [релизов](https://github.com/compico/oc-plugins/releases) (теги `osu-skills-v<версия>`), положите в папку плагинов OC и нажмите «Rescan».
2. В «Plugin store… → Standalone plugins…» выдайте разрешение `net.http`.
3. Add Source → Plugins → «osu! skills graph» (520×220, прозрачный фон). tosu должен быть запущен.

Если tosu слушает не на `127.0.0.1:24050`, поменять адрес можно параметром `?tosu=host:port` в адресе виджета, а ширину окна точек — `?window=мс` (по умолчанию 5000).

## Настройки

- **Источник файлов карт** (`source`): ссылка на `.osu`, `{id}` заменяется ID сложности. Только `https`. По умолчанию `https://osu.ppy.sh/osu/{id}`;
  если этот адрес не отдаёт файлы, укажите зеркало.

## Ограничения

- Файл карты берётся по ID сложности из сети (плагину запрещено ходить в локальную сеть, поэтому читать файл у tosu он не может). Карты без ID (локальные, не загруженные) не поддерживаются.
- Файл карты больше 1 МиБ (например, со сложным сториборд) не помещается в ответ хоста: виджет покажет ошибку.
- Размер плагина около 5 МБ (рантайм Go и расчёт навыков).

Навыки считает go-osu: значения совпадают с карточкой карты в go-osu. Кривые на одной шкале (максимум по карте = 100 % высоты).
