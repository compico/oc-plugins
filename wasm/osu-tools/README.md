# osu-tools — инструменты osu! для стрима

Автономный (standalone) wasm-плагин для Overlay Composer: **график навыков** текущей карты (виджет) и команда чата **`!np`**
(ссылка на текущую карту). Заменяет плагины `osu-skills` и `osu-np`: один источник, один адрес tosu, одни разрешения.

## График навыков

Автономный (standalone) wasm-плагин для Overlay Composer. Виджет рисует, как по ходу карты меняется сложность каждого навыка
(stamina, tenacity, agility, precision, reading, memory, accuracy, reaction), и отмечает текущий момент. Это [osuskillsgraph](https://github.com/compico/osuskillsgraph)
и расчёт [go-osu](https://github.com/compico/go-osu) в одном виджете: поднимать go-osu больше не нужно.

## Как работает

1. Хост Overlay Composer сам держит websocket к tosu (`ws://127.0.0.1:24050/websocket/v2`, ретранслятор `net.local streams`) и публикует событие `live`:
   путь к файлу карты (`directPath.beatmapFile`), контрольную сумму, моды (HD, DT, HR, FL…) и время в карте, не чаще 4 раз в секунду. Хост подключается
   только пока виджет подписан на событие, wasm-плагин при этом не вызывается (нагрузка на процессор ничтожна). Напрямую из виджета websocket не работает:
   он в sandbox-iframe с `Origin: null`, и tosu отвечает 403; опрос HTTP из плагина давал 3–4 % CPU.
2. Виджет, получив событие, просит у плагина кривые (`POST /plugins/osu-tools/api/curves`). Плагин забирает файл `.osu` у самого tosu (`http://127.0.0.1:24050/files/beatmap/…`,
   разрешение `net.local`), считает кривые библиотекой [`github.com/compico/go-osu/pkg`](https://github.com/compico/go-osu/tree/master/pkg) и отдаёт их в формате ручки go-osu `/strains`.
3. Виджет рисует график. Пока файл загружается, плагин отвечает 202, и виджет повторяет запрос; карты и результаты кэшируются в памяти плагина.

Разрешение графика: `net.local` (только адрес tosu: websocket `/websocket/v2` и файлы карт `/files/beatmap/`). В интернет плагин не ходит, ID карты не нужен: работают и локальные карты.

## Установка

1. Скачайте `osu-tools.wasm` из [релизов](https://github.com/compico/oc-plugins/releases) (теги `osu-tools-v<версия>`), положите в папку плагинов OC и нажмите «Rescan».
2. В «Plugin store… → Standalone plugins…» выдайте разрешения `net.local`, `chat.command.read` и `chat.send`.
3. Add Source → Plugins → «osu! skills graph» (520×220, прозрачный фон). tosu должен быть запущен, папка Songs указана в настройках tosu.

Если tosu слушает не на `127.0.0.1:24050`, укажите адрес в настройке плагина `tosuHost`. Стиль и окно точки настраиваются в самом виджете (см. ниже).

## Настройки виджета

Стиль и окно точки настраиваются **у самого виджета**: выберите источник на сцене, форма настроек появится в свойствах (у каждого источника на сцене они свои).
Значения приходят виджету как `?style=…&window=…`, так что их можно задать и вручную в адресе.

- **Стиль**: выпадающий список, по умолчанию `ribbon`.
  - **ribbon**: одна «гора»: высота — самый тяжёлый навык в каждый момент, цвет — какой навык ведёт. Снизу тонкая полоса «кто где ведёт», в легенде жирным выделен текущий ведущий.
  - **silhouette**: силуэт всех навыков полупрозрачным серым; там, где навык ведёт, он закрашен своим цветом с мягкими краями.
  - **lines**: по линии на навык (как в 0.1–0.4); навыки, которые тяжелы прямо сейчас, ярче.
  - **spectrum**: «спектрометр»: столбик на каждый навык, сегментами, как у анализатора спектра. Высота — текущее значение навыка (общая шкала, как у остальных стилей; кривые для него считаются с окном 200 мс и интерполируются, поэтому столбики двигаются в такт карте),
    растёт быстро, опускается плавнее; метка пика держится полсекунды. Перерисовка идёт, только пока столбики движутся.
- **Окно точки, мс** (`window`): 500–60000, по умолчанию 5000. На длинных картах больше значение — плавнее график; на spectrum не влияет (там окно фиксировано, 200 мс).

Чтобы цвет в ribbon и silhouette не дёргался, когда навыки идут рядом: значения сглаживаются по соседним окнам, ведущий меняется, только если соперник выше на 15 %,
а отрезок короче трёх окон отдаётся соседу. Memory в этих стилях не участвует (у неё накопительная кривая).

## Команда !np

Зритель пишет `!np` (регистр не важен, можно с аргументами: они игнорируются) — плагин отвечает ссылкой на карту, которая выбрана или играется:
`Artist - Title [Version] https://osu.ppy.sh/beatmaps/123`. Команда работает **на сервере OC**: открытый оверлей и виджет не нужны, достаточно запущенных OC и tosu.

- Чат читает общее соединение OC (канал аккаунта Стримера из настроек OC). Плагин получает только `!np` (`chat.command.read`), остальной чат ему не виден.
- Ответ уходит от аккаунта бота (`chat.send`), по умолчанию — реплаем на сообщение зрителя.
- Данные — `GET /json/v2` у tosu (`net.local`, путь `/json/`). Если карты нет на сайте (id = 0) — отвечает `unsubmittedText`; если tosu недоступен — `offlineText`.
- Повтор того же текста в течение 35 с Twitch не пропускает: плагин добавляет невидимый символ.

## Настройки плагина

Форма настроек плагина показывает текстовые поля; значения такие:

- **Адрес tosu** (`tosuHost`): `host:port`, только loopback (`127.0.0.1`, `localhost`, `[::1]`). По умолчанию `127.0.0.1:24050`. Общий для графика и `!np`.
- **`who`**: кто может `!np`: `everyone` (по умолчанию), `sub` (подписчики и выше), `vip`, `mod` (модераторы и стример). Стример и модераторы могут всегда.
- **`cooldownSeconds`**: общая пауза между ответами, 0..600, по умолчанию 15.
- **`replyToUser`**: `true` (по умолчанию) — ответ реплаем, `false` — обычное сообщение.
- **`template`**: текст ответа, подстановки `{artist} {title} {version} {mapper} {stars} {id} {set} {url} {user}`; по умолчанию `{artist} - {title} [{version}] {url}`.
- **`unsubmittedText`**, **`offlineText`**: ответы для карты не с сайта и для недоступного tosu.

## Переход с osu-skills и osu-np

Id плагина изменился, поэтому: положите `osu-tools.wasm`, удалите старые `osu-skills.wasm` и `osu-np`; добавьте источник заново (Plugins → «osu! skills graph»), выдайте разрешения заново.
Из настроек `osu-np` не переносятся `channel` (теперь канал из настроек OC) и `command` (команда всегда `!np`); остальные (`who`, `cooldownSeconds`, `replyToUser`, `template`, `unsubmittedText`, `offlineText`, `tosuHost`) называются так же.

## osu!stable и osu!lazer

Работает и с тем и с другим клиентом: tosu отдаёт путь к карте в `directPath.beatmapFile`. У stable это «папка\файл.osu», у lazer — путь в хранилище по хэшу без расширения («8\8f\8f50d5…»).
Папка Songs в tosu должна указывать на карты: у lazer это каталог `files` (например `D:\osu-lazer\files`). Остальные поля (`beatmap.checksum`, `play.mods.name`, `beatmap.time.live`) у клиентов одинаковые.
Расчёт сейчас только для osu!standard.

## Ограничения

- Файл карты больше 8 МиБ плагин не принимает. Кривые в ответе ограничены 1 МиБ.
- Размер плагина около 5 МБ (рантайм Go и расчёт навыков).
- Требуется версия Overlay Composer с `net.local streams` (overlaycomposer#148), настройками виджета (overlaycomposer#154) и командами чата `chat.command.read` (overlaycomposer#158, реплаи — тот же PR).
- `!np` отвечает только в чат канала по умолчанию, команды и канал не настраиваются. Настройки плагина — текстовые поля (select в форме для wasm-плагинов пока нет).

Навыки считает go-osu: значения совпадают с карточкой карты в go-osu. Кривые на одной шкале (максимум по карте = 100 % высоты).
