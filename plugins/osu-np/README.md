# osu! `!np`

Отвечает в чате Twitch на команду `!np` ссылкой на карту osu!, которая сейчас выбрана или играется на стриме:

```
Camellia - Exit This Earth's Atomosphere [Evolution] https://osu.ppy.sh/beatmaps/1234567
```

Карту плагин узнаёт у [tosu](https://github.com/KotRikD/tosu) (`http://<адрес>/json/v2`, запрос делает сервер OC — разрешение `net.local`, правило `netLocal`: адрес берётся из настройки «tosu address», доступны только пути `/json/…`), поэтому tosu должен быть запущен на том же компьютере, что и OBS
(или быть доступен по сети — адрес задаётся в настройках).

## Что нужно

1. Overlay Composer с подключёнными аккаунтами Twitch (Settings → Twitch accounts): **Bot** (от его имени пойдёт ответ; если не подключён — от Стримера) и/или **Streamer**.
2. Запущенный tosu.
3. Виджет в одном из layout, который показывается в OBS **всё время стрима** (плагин работает, пока открыта страница оверлея). Размер слоя не важен: он прозрачный.

## Установка

Скопируйте папку `osu-np` в папку плагинов OC (Add Source → **Open plugins folder**), затем Add Source → **osu! !np command**.
При добавлении согласитесь на разрешения: `chat.read` (слушать чат) и `chat.send` (отвечать).

## Настройки

| Настройка | По умолчанию | |
|---|---|---|
| Twitch channel | пусто | пусто — канал аккаунта Стримера |
| Command | `!np` | команда — первое слово сообщения, регистр не важен |
| Who can use it | everyone | everyone / subscribers+ / VIPs+ / moderators + broadcaster |
| Cooldown, seconds | 15 | общая пауза между ответами |
| Reply to the user's message | вкл | ответ ветка-«reply» на сообщение зрителя |
| Message | `{artist} - {title} [{version}] {url}` | подстановки: `{artist} {title} {version} {mapper} {stars} {id} {set} {url} {user}` |
| Map is not on osu! | текст | если карта локальная/не загружена на сайт (`id = 0`) |
| tosu is not reachable | текст | если нет данных от tosu |
| tosu address | `127.0.0.1:24050` | `host:port` |
| Show status on the widget | выкл | показывает соединение с tosu, карту и последние команды (для проверки) |

## Заметки

- Ссылка короткая: `https://osu.ppy.sh/beatmaps/<id сложности>`.
- Если оверлей открыт сразу в нескольких местах, ответ всё равно отправится один раз (OC отбрасывает дубликаты ответов на одно сообщение).
- Twitch не пропускает два одинаковых сообщения подряд за короткое время; плагин добавляет к повтору невидимый символ.
- В предпросмотре редактора ответы отключены — чтобы проверить, включите «Show status» и напишите `!np` в чат, а отправку смотрите в OBS.
