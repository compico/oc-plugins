# fps-meter

Счётчик частоты кадров и времени кадра. Добавьте его слоем в тот же layout, где «просаживается» FPS, и смотрите на цифры
в OBS или на стриме. Разрешения не нужны.

## Что показывает

| Показатель | Смысл |
|---|---|
| крупное число | кадров в секунду за последнюю секунду (зелёное/жёлтое/красное — по среднему времени кадра относительно цели) |
| `avg / p95 / max` | время кадра (мс) за окно: среднее, 95-й процентиль, самый долгий кадр |
| `slow a/b` | сколько кадров из `b` были дольше 1,5× целевого времени |
| `missed` | оценка пропущенных кадров (`время кадра / целевое − 1` для долгих кадров) и их доля |
| `target` | целевая частота: выбранная в настройках или «ближайшая стандартная» по медиане |
| `timer lag` | на сколько опаздывает таймер на 50 мс внутри самого виджета (занятость его процесса) |
| график | худшее время кадра на каждом отрезке окна; белая линия — целевое время кадра, шкала до 4× |

## Как пользоваться, чтобы найти виновника

1. Добавьте `fps-meter` на layout и посмотрите цифры при выключенных «тяжёлых» виджетах: это базовая линия.
2. Включайте виджеты по одному (глаз у слоя). Когда `avg`/`p95` вырастают, а `fps` падает ниже цели — виджет найден.
3. Сравните с тем же виджетом, добавленным отдельным Browser Source в OBS (без OC), и с настройкой **Custom frame rate** у источника OC.

## Что это измеряет, а что нет

- Измеряется частота `requestAnimationFrame` **в iframe самого счётчика**. Кадры задаёт общий композитор страницы оверлея,
  поэтому, если страница в целом не успевает рисоваться (тяжёлая анимация другого виджета, перерисовка всего холста, медленная
  композиция в OBS), частота падает и здесь. Но счётчик не видит, **какой именно** виджет виноват, — для этого нужно включать/выключать виджеты.
- Плагины и iframe-виджеты работают в отдельных процессах: тяжёлый JavaScript другого виджета не замедлит таймер этого, но
  отрисовку он замедлить может.
- В редакторе OC (предпросмотр) частота — это частота окна браузера (обычно 60/144 Гц), а не настройка OBS. Настоящие цифры — в OBS.
- Сам счётчик лёгкий: время кадра пишется в `requestAnimationFrame`, текст и график обновляются 4 раза в секунду.
  Для чистого эксперимента можно отключить график (**Show graph**).
